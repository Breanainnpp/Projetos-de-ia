# Projetos-de-ia
O projeto de Inteligência Artificial integrada a robôs autônomos, focada na otimização de processos, navegação em tempo real e aumento da precisão operacional.
Tecnologias: Linguagens de programação e componentes de Hardware 
Desenvolvimento de sistemas embarcados e automação de hardware utilizando microcontroladores (como o Arduino Uno R3) e sensores físicos (como o TTP223B capacitivo, sensores LDR, módulos PWM e circuitos de simulação de motores de portão). O documento conecta a eletrônica prática ao desenvolvimento de software, destacando a integração de C++ para a programação de microcontroladores no ecossistema Arduino e C# para aplicações de controle, interface ou gerenciamento externo em ambiente desktop/sistema.
